# Evidence discipline

FactoryPulse intentionally separates current evidence from future Phase-2 claims.

## Verified in the portfolio project

- Local telemetry processing
- Isolation Forest anomaly detection
- Interpretable risk scoring
- Energy baseline heuristic
- Local benchmark of the anomaly pipeline
- Optional OpenAI-compatible inference adapter

## Not claimed yet

- Kompact AI benchmark numbers
- Kompact AI latency
- Kompact AI memory usage
- Actual factory savings
- Production failure prediction accuracy

Those claims should only be added after measurement or real deployment evidence exists.

This is deliberate: a technically honest submission is easier for reviewers to trust.
